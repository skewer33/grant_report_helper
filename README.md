# Бот для ведения отчётности и загрузки документов на Яндекс.Диск

Телеграм-бот для ведения отчётности по грантам и проектам.

Позволяет:

* создавать записи о расходах,
* прикреплять к ним отчётные документы,
* автоматически загружать документы на Яндекс.Диск,
* хранить структуру расходов в CSV,
* экспортировать отчёт в Excel.

Бот создан для упрощения подготовки финансовой отчётности по грантам и проектам.

## Основные возможности

### ➕ Новый расход

Создание новой записи о расходе.

Бот последовательно запрашивает:

* название расхода,
* категорию,
* статью расходов,
* сумму,
* дату.

После подтверждения создаётся запись вида:

```text
EXP001
EXP002
```

Информация сохраняется в:

```text
data/<template>/expenses.csv
```

---

### 📎 Добавить документ

Позволяет прикрепить отчётный документ к существующему расходу.

Поддерживается загрузка:

* чеков,
* договоров,
* актов,
* счетов и других документов.

Документы автоматически:

* переименовываются,
* загружаются на Яндекс.Диск,
* привязываются к расходу.

Пример имени файла:

```text
EXP001_contract_22000.pdf
```

Файлы сохраняются в структуре:

```text
Документы/<template>/<category>/
```

---

### 📄 Выбрать шаблон

Позволяет переключаться между разными проектами или грантами.

Для каждого шаблона:

* создаются отдельные expenses.csv и attachments.csv,
* ведётся собственная нумерация расходов,
* хранится отдельная структура документов.

---

### ✏️ Создать шаблон

Загрузка Excel-шаблона со статьями расходов.

Шаблон должен содержать столбцы:

* Категория
* Статья Расходов

Пример находится в:

```text
Templates/Example.xlsx
```

---

### 📋 Последние расходы

Показывает список последних созданных расходов.

---

### 🔍 Посмотреть расход

Показывает:

* информацию о расходе,
* прикреплённые документы,
* связанные файлы.

---

### Экспорт

Создаёт Excel-файл с:

* расходами,
* прикреплёнными документами.

## Подготовка к запуску

Перед запуском необходимо:

1. Создать Telegram-бота через [@BotFather](https://t.me/BotFather?utm_source=chatgpt.com) и получить API_TOKEN

2. Получить OAuth-токен Яндекс.Диска:
   [Yandex Disk OAuth Guide](https://yandex.ru/dev/disk-api/doc/ru/concepts/quickstart?utm_source=chatgpt.com#quickstart__oauth)

---

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/skewer33/grant_report_helper.git
```

Создайте:

* `.env`
* `authorized_users.txt`

и заполните их по примеру из:

```text
list_necessary_files.txt
```

Если не знаете свой Telegram user_id — отправьте боту `/start`.

---

## Запуск

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите бота:

```bash
python bot.py
```

---

## Структура проекта

```text
Templates/        # локальный кеш шаблонов

```
